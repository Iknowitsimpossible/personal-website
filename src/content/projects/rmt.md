## About the project

RMT (Rate My Teacher) is a school-focused review platform for BIPH. I worked on this project in 2025 to help students share classroom experiences and learn more about teachers and classes.

## How it works

Students can browse teachers, search by name, and filter by subject. Teacher profiles bring together overall quality, course difficulty, rating distributions, and whether students would take the teacher again.

Reviews combine ratings with written comments and descriptive tags. Students sign in to contribute, while their usernames stay hidden on public reviews. The platform limits each account to one review per teacher and supports votes on reviews.

## Built with

The application uses Next.js, React, and TypeScript for the interface and server-side actions, Tailwind CSS for styling, and Supabase for data storage and authentication. The repository also includes tools for managing teachers and reviews, along with a support-ticket workflow.
