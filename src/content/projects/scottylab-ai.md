## What the team does

[ScottyLabs](https://scottylabs.org/) AI connects AI assistants with CMU campus data and services, including dining, locations, and transit. I’m part of the Agent team, whose tasks include **an MCP marketplace**, **an SMS integration proposal**, **more reliable tool loading and memory recall beyond keyword matching**, and **reducing delays in response streaming and moderation**.

Through this work, I’m learning backend development, API integration, testing, and collaborative software development. It’s also helping me understand how AI agents select tools, recall context, and balance responsiveness with moderation.
